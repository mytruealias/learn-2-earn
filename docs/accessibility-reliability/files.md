## Review boundaries

The additive migration creates only HttpRateLimit and its required primary key/positive-count constraint. Existing ledger, program, session, attempt, support and inquiry histories remain intact. Presentation, transport and diagnostics changes do not change payout rates, balances, entitlements or authored curriculum. No other query index was introduced without a measured query plan.

Test suites use either the existing nonce-attested fresh database harness or intentionally unusable database bindings and explicit synthetic browser interception. The new production lab has not produced route timings because the pinned Prisma download is blocked. Exact SQL-service evidence uses a disclosed parameterized pg adapter, not a substitute generated client.
